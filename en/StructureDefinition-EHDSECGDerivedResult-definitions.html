0. EHDSECGDerivedResult
Definition

One envelope for measurements, diagnostic statements, AI inferences and other derived biomarkers. The meaning of a non-standard result lives in a versioned definition (EHDSECGBiomarkerDefinition). Typical Core uses: the global measurement set (type measurement-set, one component per LOINC measurement) and the diagnostic statement set (type statement-set, one component per SNOMED CT finding).
