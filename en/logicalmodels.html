Logical Models

This page lists the logical models (information models) that this Implementation Guide realises with HL7 FHIR profiles.

The ECG specific models are defined by this Implementation Guide. They build on the common Xt-EHR EHDS Logical Information Models (patient, health professional, organisation, device, document, observation…), which are reused as they are.

Not part of the EHDS logical models: The ECG models listed in ECG Logical Models (specified by this guide) are specified by this Implementation Guide. They are not part of the Xt-EHR EHDS Logical Information Models, nor of the EHDS logical information models referred to in Article 15 of the EHDS Regulation, even if their names use the EHDS prefix and they derive from Xt-EHR base models. They are based on the ESC EHDS ECG Standard (working draft v0.6), and are proposed as input for the future EHDS models covering ECG reports.

ECG Logical Models (specified by this guide)

Documents

Model Based on (Xt-EHR) Description
EHDSECGReport EHDSDocument The exchangeable unit for the EHDS priority category medical test results (Regulation (EU) 2025/327, art. 14(1)(e)). Sibling of EHDSLaboratoryReport.
EHDSECGResultDocument EHDSDocument Transports annotations and derived results produced after the ECG was first exchanged (for example an AI analysis of an archived ECG or a later re-reading), without rebuilding the original report.

Examination, Recording and Results

Model Based on (Xt-EHR) Description
EHDSECGExamination EHDSObservation One acquisition session (a resting 12-lead ECG, a stress test, a Holter recording…). It groups the signal, the annotations and every result derived from it.
EHDSECGRecording EHDSDataSet The waveform and its acquisition metadata, which the Xt-EHR models do not provide.
EHDSECGDerivedResult EHDSObservation One envelope for measurements, diagnostic statements, AI inferences and other derived biomarkers.
EHDSECGAnnotationSet EHDSDataSet Time-anchored annotations. One set = one author (algorithm or person) at one time.

Algorithms and Biomarkers

Model Based on (Xt-EHR) Description
EHDSECGAlgorithm EHDSDevice An algorithm that produces ECG derived results, with the performance of this version of the algorithm.
EHDSECGBiomarkerDefinition – Registry entry for a derived or AI biomarker, equivalent to FHIR R5 ObservationDefinition.

Secondary Use

Model Based on (Xt-EHR) Description
EHDSECGResearchRecord – Research extraction profile for EHDS secondary use (chapter IV of the Regulation): one record per pseudonymised subject.
EHDSECGResearchDataset – Description of a research dataset, i.e. a set of EHDSECGResearchRecord. Also described in the health data catalogue with HealthDCAT-AP.

Xt-EHR Logical Models used by the ECG Report

The following models are part of the Xt-EHR EHDS Logical Information Models and are reused by this guide.

Model Description
EHDSDocument EHDS refined base model for a document
EHDSObservation EHDS refined base model for medical test results and other clinical observations
EHDSDataSet EHDS base model for a data set
EHDSDevice EHDS refined base model for Device information
EHDSPatient EHDS refined base model for Patient (subject of care)
EHDSHealthProfessional EHDS refined base model for Health Professional
EHDSOrganisation EHDS refined base model for healthcare organisations and providers
EHDSAttachment EHDS refined base model for containing or referencing attachments
